# Péntek László – személyes portfólió

A projekt helye: D:\ai\Péntek László

## Aktuális állapot
Projektindítás és briefellenőrzés kész. Az alkalmazás fejlesztése még nem indult el, ezért nincs indító- vagy buildparancs.

- brief.md: eredeti megrendelői brief.
- .webprojekt/brief-ellenorzes.md: ellenőrzés, alapanyag-leltár és nyitott tartalmi kérdések.
- assets/: eredeti logó és fotók; változatlanul megőrzendők.

## Munkamenet
1. Tartalom tisztázása és vizuális koncepciók.
2. Kiválasztott irány megvalósítása, a brief alapján React/TypeScript/Vite technológiával.
3. Optimalizálás, build és böngészős ellenőrzések.
4. Dokumentáció az indításról, tartalomszerkesztésről és publikálásról.

A frontend-design, tervezes és generalas skillek a felhasználói Codex skillmappában vannak telepítve. A Git-repó helyi; nincs beállított távoli repo vagy automatikus publikálás.
